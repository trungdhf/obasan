# 提出フォーム用 説明文（下書き）

## プロジェクト名
Hinata（ひなた）— 一人暮らしのおばあちゃんと話す、見守りアバター

## 対象ユーザーと課題

日本では一人暮らしの高齢者が増え続けています。離れて暮らす家族にとって、
「元気かな」「ごはん食べたかな」「薬飲んだかな」は毎日の心配です。
一方で、高齢者にとってスマホの通知やアプリの操作は負担が大きく、
既存の見守りサービスは「センサーが動きを検知するだけ」で会話の温かみがありません。
特殊詐欺（オレオレ詐欺）の被害も増えており、日々の注意喚起が求められています。

## ソリューション

タブレットに置くだけの見守りアバター「ひなた」。
**エージェントが自分で「いつ話すか、いつ休むか、いつ家族に知らせるか」を判断する**、
質問待ちのチャットボットではない companion です。

- **話しかけてくれる**: 顔を見つけると自分から挨拶し、音声で自然におしゃべり
  （Gemini Live・日本語・ゆっくりはっきり）。雑談だけでなく、なぞなぞ・昔話・
  脳トレ・体操・唱歌・ニュース・天気まで一人で盛り上げます。
- **自分で休む・課金も休む**: 顔がいなくなると「じゃあね」と言って
  Gemini Live セッションを自分で切断（料金ゼロ）。戻ると記憶を引き継いで再開。
- **忘れ物を教えてくれる**: Cloud Scheduler の定時ジョブが薬・水分の
  リマインダーや食後の「ごはん・おくすり」の聞き取りを発火。
  応答がなければ最大3回呼びかけ（Live未接続のまま TTS で＝課金ゼロ）。
- **迷わず家族に頼る**: 応答なし・「食べてない」続き・体調不良の発言を
  検知すると、メールまたはLINEで家族に通知。最終判断は必ず人間に委ねます。
- **食事・服薬・体調・気分を記録**: 会話から拾った「食べた/まだ/飲み忘れた」
  「つかれた」「さびしい」を health_log に記録し、家族があとから確認できます。
- **詐欺の注意喚起**: 1日1回、やさしく「しらない電話でお金の話をされたら
  かぞくに電話してね」と声かけ。おばあちゃんが「おかしな電話があった」と
  話せば「それはさぎかも！」とその場で警告し、家族にも通知します。

## 家族ダッシュボード（/family）

離れた家族がブラウザで確認できるページ：
- 今いる/いない（顔検出の最新状態）
- 今日の各食後の ごはん・おくすり・げんき・きぶん の4項目 + 7日分の表
- ひなたが覚えている会話の要約（おばあちゃんが話した近況）
- 脳トレゲームの成績（ラウンド・正解数・ミス数）
- 予定しているリマインダーと行動タイムライン（呼びかけ・通知履歴）

## 楽しいコンテンツ

- **昔話471話**: 青空文庫の童話・昔話（楠山正雄・小川未明・新美南吉ほか）を
  収録。「おはなしして」で順番に読み聞かせ。話を考えるのではなく、
  本物の物語を読みます。
- **脳トレゲーム**: 絵柄を覚えて、似た絵の中から正解を選ぶ記憶ゲーム。
  ラウンドが上がると覚える数が増えます（成績はサーバーに記録）。
- **なぞなぞ・しりとり・計算クイズ**: 会話の中で自然に出題。
- **唱歌**: ふるさと・ももたろう などパブリックドメインの録音を再生、
  歌詞を表示していっしょに歌えます。
- **体操**: NHK「みんなの体操」流のシニア向け7動作を、ひなたが動きで
  お手本を見せながら声でガイド。
- **返事ボタン**: ひなたが質問すると画面下にタップ用の回答ボタンが出ます
  （show_reply_options ツールで質問に合った選択肢を自動生成）。
  声が出しにくい日でも指一本で返事できます。

## 特徴（Agentic な点）

1. **自律的な発話タイミング**: 顔検出・時刻・警報・家族通知・会話の流れから
   エージェント自身が「話す/休む/呼びかける/家族に知らせる」を選択。
2. **コストを意識した agentic 設計**: 課金が走るのは顔がある間だけ。
   呼びかけは事前合成 TTS で行い、応答があって初めて Live に接続する。
3. **ツール駆動**: set_emotion（表情）、notify_family、schedule_reminder、
   get_weather/get_weather_alert（気象庁）、get_news（NHK）、
   get_story（青空文庫471話）、start_memory_game、record_game、
   play_song/stop_song、play_animation（12種の.vrmaモーション）、
   show_reply_options（返事ボタン）、record_health、save_memory を
   LLM が自律発動。
4. **プライバシー配慮**: 顔検出は MediaPipe でオンデバイス処理（画像は外に出ない）。
   会話の音声・文字起こしはサーバーに保存しない。家族のメッセージは
   「伝達データ」として扱い、命令文として実行しない設計。
5. **多言語**: 日本人向けのほか、`?lang=vi` でベトナム語モード
   （在留高齢者・帰国後の実証用）。天気はホーチミン、ニュースはVnExpressに
   自動切替。

## 使用技術

- **実行**: Cloud Run（asia-northeast1）— backend(Node/Express) + web/ 静的配信
- **AI**: Vertex AI — Gemini Live（BidiGenerateContent, ネイティブ音声対話・
  ツール呼び出し）+ Gemini Flash TTS（呼びかけ・別れの挨拶の音声合成）
- **その他GCP**: Firestore（記憶・リマインダー・ログ・health_log・game結果）、
  Cloud Scheduler（/jobs/due, /jobs/health-check）、Secret Manager、Cloud Build
- **連携**: Gmail SMTP（メール通知）・LINE Messaging API（任意）、
  気象庁JMA、NHK RSS、Open-Meteo、VnExpress RSS
- **フロント**: 純粋な静的HTML/JS — three.js + @pixiv/three-vrm（VRMアバター・
  .vrma アニメーション12種 + 手続き型体操モーション）/ 手描きSVGアバター、
  MediaPipe FaceDetector、Web Audio（リップシンク・PCM再生）、Wake Lock

## 動作確認の方法（審査員向け）

1. https://hinata-1046503390224.asia-northeast1.run.app/ を開く
   （Chrome 推奨・スピーカーON。**マイクを許可**してください。カメラは任意——
   許可しなくても、声でおばあちゃんの存在を判定して動きます）
2. 「はじめる」をタップ → ひなたが起きて、Gemini Live の声で挨拶します。
   そのまま日本語で話しかければ、音声で会話できます
3. 画面左右のアイコンバーから各機能を試せます：
   📖おはなし（昔話）/ 🧠のうとれ（記憶ゲーム）/ 🤸たいそう（体操）/
   🎵うた（唱歌）/ 📰ニュース / 🌤️てんき / ☎️かぞく（家族通知テスト）
   / 🔁もういっかい・⏭️つぎ（聞き直し・次へ）
4. 家族向けページ: /family（おばあちゃんの状態・記録の閲覧画面）
5. ベトナム語モード: ?lang=vi（ベトナム語で話しかけると、ベトナム語で答えます）

※ マイクが使えない環境では `?demo=1`（デモモード）で画面と機能の流れを確認できます。
デモモードは Gemini Live の会話を使わず、決まったセリフをひなたの声（録音済み音声／
Gemini TTS）で再生します。メール/LINE通知・カメラ連動の自動おやすみは実機環境向け
機能のため、パネルのボタンで確認できます。
